---
title: 'Descarga Guía XML'
openapi: 'GET /sunat/guia/xml/{numRuc}-{tipoDocumento}-{numSerieComprobante}-{numDocumentoComprobante}'
---

## Parámetros de la guía

| Parámetro | Ejemplo | Descripción |
|-----------|---------|-------------|
| numRuc | 20123456789 | Número de RUC del emisor. |
| tipoDocumento | 09 | Tipo de documento electrónico. |
| numSerieComprobante | T112 | Serie del comprobante. |
| numDocumentoComprobante | 6621 | Número del comprobante. |

### URL de ejemplo

```text
GET /api/sunat/guia/xml/202645878-09-T112-6621
```

### Ejemplo de respuesta

```json
{
  "success": true,
  "message": "Exito",
  "data": "PTYDF553BhdGNoQWR2aWNl..."
}
```
